# 剧本数据

## 1947-01-01-world.json

- 剧本名称：1947年1月1日：战后世界与冷战前夜
- 开局时间：`1947-01-01T00:00`
- 规模：80 个政权、130 位领导人、4,465 块领土（4,411 条下级行政区 + 54 条无地区数据的整国编号）
- 内容：1947 年 1 月 1 日的现实世界，按当时实际存在的国家、占领区与殖民地当局建模
- 速览：[`1947-01-01-world.md`](1947-01-01-world.md)（同一份数据的分区表格，便于快速查阅）

### 导入方式

1. 打开「剧本编辑」页面（`/pages/scenario-editor`）；
2. 点击顶部「导入剧本 JSON」，选择本文件；
3. 世界视图只给 54 个「没有下级行政区数据」的整国条目上色，放大到 2.4 倍后会加载并显示各国的地区色（中国为地级市，能看到中华民国与解放区的分界）；
4. 需要微调时可直接改 JSON 再导入，或在页面里编辑后重新导出。

### 字段口径

- 每个政权的「经济状况」就是该国 1947 年初的一句话国情概述（以经济为主，兼及政治与外交）；「政治制度」是同一政权的制度说明。
- 国情概述与领导人简介只写 1947-01-01 当时的状态、压力和已有趋势，不写之后必然发生的事件；具体走向交给事件推演。
- 每位领导人的「简介」都是一句话，方便事件推演时引用。殖民当局/托管地里的对立运动领袖，在 `职位` 后标注「对立势力领袖」或「社群领袖」。
- 初始国家力量为 -100 ~ 100：政治稳定、经济发展、国际影响。
- 「AI控制」全部为 `true`（由模型推演各国国策）；若要自己操纵某国，可把该政权的 `AI控制` 改成 `false`。
- `国家指标` 与 `初始国家力量` 数值相同，导入时会自动保持同步。
- 城市、政党、种族、科技等深层档案字段未展开填写，导入后按空值处理，可在「国家档案」页继续补全。

### 领土粒度

- 全部领土按下级行政区记录，每条包含 `名称`、`代码`、`级别`（adm1/adm2/adm3）与 `国家代码`。
- 地区编号有三种：ISO 3166-2（如 `DE-BY`、`FR-IDF`）、中国 adcode（如 `610600` 延安市），以及源数据没有 ISO 代码的国家使用的 `ISO:要素ID`（如 `AUS:25037944B24790092852260`）。后者在界面上显示地区名称，编号只用于匹配地图。
- 源数据存在 `N/A` 这类重复编号（Abyei 与 Keserwan-Jbeil），应用层按「代码 + 国家代码」区分领土，不再只按代码匹配。
- 54 个地区在内置地图里没有可用的下级行政区数据，保留整国 ISO3 编号：西班牙、阿曼（源数据里所有地区的编号都是国家代码，无法区分）、利比亚、马耳他、摩尔多瓦、黑山、科索沃、格陵兰、法罗群岛、奥兰群岛、西撒哈拉、克什米尔，以及若干小岛（关岛、美属萨摩亚、马绍尔群岛、百慕大等）。这些条目可以删除，但不能再按地区选择。
- 源数据里 32 个重复编号已跳过：西班牙、阿曼整体退回整国；拉脱维亚、冈比亚、中非、越南、伊朗、墨西哥、厄瓜多尔各 1 个重复只保留首条，对应两块地图要素共用同一编号。
- 地区名称沿用地图数据本身（中国为中文，其余多为当地语言/英文），便于与地图悬停提示一致。

### 建模取舍

- **边界**：领土使用现代国界与行政区划，与 1947 年的实际控制线不同（德波边界、克什米尔、满洲、巴勒斯坦、朝鲜半岛、的里雅斯特等）。
- **殖民帝国合并建模**：英国、法国、荷兰、比利时、葡萄牙、西班牙、丹麦的殖民地并入宗主国领土；但英属印度、法属印度支那、荷属东印度、巴勒斯坦托管地单独成政权，因为它们正处在独立、战争或分治的关口。
- **占领区**：德国、奥地利、日本、朝鲜南部、利比亚建模为占领/军管政权；北朝鲜为临时人民委员会；意大利前殖民地中的厄立特里亚、索马里暂列英国军管。
- **中国**：中华民国领有大陆与台湾；中国共产党（解放区）按 1947 年初主要根据地所在的地级市近似（adcode，如延安 `610600`），华北、山东、北满等 20 个地级市先归解放区，其余地级市归中华民国。
- **人口**：取该政权总人口；英、法、荷、比、葡等帝国型政权取本土人口，殖民地人口未计入。相关政权在 `名词定义` 中增加了「人口口径」说明。
- **未分配**：安道尔、摩纳哥、圣马力诺、列支敦士登、梵蒂冈等微型国家与南极领地未分配，地图上保持未着色。
- **属地**：香港、澳门、苏丹、西南非洲、巴布亚新几内亚等属地/托管地并入宗主国，名称中标注了 1947 年的属性。

### 校验

生成时逐项校验了：领土编号全局不重复（4,465 条）、每条地区都能在内置地图的下级行政区数据里找到、代表色与政权名不重复、领导人简介与国情概述均为单句、国家力量在 -100 ~ 100 内；并用 `src/utils/scenario-data.ts` 的 `normalizeScenarioData`、`serializeScenarioForExport`、`toCountryData` 做过往返校验。整份文件导入「剧本编辑」后实测：80 个政权载入约 0.5 秒，草稿约 0.32 MB；澳大利亚 547 条哈希编号与地图运行时编号逐条一致，点选地区可正常加入/移出。应用层还按「代码 + 国家代码」处理 Abyei / Keserwan-Jbeil 等源数据重复编号。
